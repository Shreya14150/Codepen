#  CodePen – Mini Code Editor (HTML, CSS, JS)

A simple and powerful **live code editor** where you can write HTML, CSS, and JavaScript — and instantly see the output on the same screen!

##  Why it’s Awesome
-  **Live Preview** – See your code work as you type!
-  **Separate Panels** – For HTML, CSS & JavaScript
-  **Modern Dark UI** – Clean and responsive layout
-  **Great for Practice** – Test ideas without any setup

##  Built With
- **HTML** – Structure
- **CSS** – Styling (Dark Theme)
- **JavaScript** – Interactivity & Output Rendering

##  Use Cases
- Quick front-end experiments
- Learning and practising web development
- Trying out UI/UX ideas on the fly
